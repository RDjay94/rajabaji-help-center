# Rajabaji Help Center

Bilingual (English / বাংলা) video tutorial site for Rajabaji — register, deposit, withdraw, reset password, play, and refer & earn.

- Full tutorial video per topic with a designed play-thumbnail
- Step-by-step annotated screenshots (key element circled) under each video
- One-tap EN ⇄ BN language toggle
- Neon-glass Rajabaji theme, responsive, offline-capable static site

## Run locally
It's a static site — just open `index.html`, or serve the folder:

```bash
npx serve .
```

## Deploy
Hosted with GitHub Pages from the `main` branch (root).
